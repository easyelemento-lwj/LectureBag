# Android Chrome 실제 촬영 시험

준비 날짜: 2026-10-08. **실제 휴대폰 시험은 아직 사용자 확인 전**이다.

## 시험 주소

https://lecturebag--drive-mobile-test-cn4bq4st.web.app

Firebase Hosting `drive-mobile-test` 채널이다. 만료 예정은 2026-10-15 13:11 KST이며 기존 공개 사이트는 변경하지 않는다.
이 주소는 링크를 아는 사람이 접속할 수 있는 미리보기이며 접근 제어 수단이 아니다. Drive API는 계속 서버의 내부 시험 UID 허용 목록으로 제한한다.

## 준비

- Android의 **Chrome 일반 탭**에서 위 주소를 연다. 카카오톡 등의 앱 안 브라우저, 시크릿 모드, 홈 화면 설치형 시험은 첫 시험과 분리한다.
- PC에서 Drive 연결에 성공한 것과 같은 LectureBag Google 계정으로 로그인한다.
- 필요한 카메라 권한을 허용한다. 사진 시험에는 마이크를 사용하지 않는다.
- 앱 센터의 Google Drive 연결 계정을 확인한다. 연결되어 있으면 불필요하게 해제하거나 다른 계정을 연결하지 않는다.
- 개인 정보가 없는 종이나 책상 등 시험용 대상을 촬영한다. 촬영 원본은 해당 Google Drive에 전송된다.
- 최초 시험에서는 앱을 열어 두고 사이트 데이터나 대기 작업을 삭제하지 않는다.

## 확인 순서

1. 카메라에서 사진 한 장 촬영 → 기기 사진 목록에 생기는지 확인.
2. 앱 센터 → Google Drive → 촬영 사진 자동 업로드에서 `Drive에 저장 완료` 확인.
3. 해당 사진의 `원본 열기`로 실제 촬영 이미지가 보이는지 확인.
4. Chrome을 새로고침 → 동일 사진이 다시 업로드되거나 Drive에서 복제되지 않는지 확인.
5. 첫 단계 성공 후 오프라인 촬영 → 앱을 유지한 채 온라인 복귀 → 저장 완료 확인.

PC `localhost`와 휴대폰 시험 주소는 서로 다른 기기 저장소다. 촬영 작업 목록은 현재 기기의 기록이며,
휴대폰 촬영 결과가 PC의 일반 탐색기에 자동 표시되는 기능은 아직 미구현이다. 필요하면 연결한 Google Drive에서 원본을 확인한다.

## 결과 기록

| 항목 | 상태 |
| --- | --- |
| Android 기종 / Android·Chrome 버전 | 미확인 |
| 로그인 및 기존 Drive 연결 확인 | 사용자 시험 대기 |
| 카메라 촬영 → 기기 저장 → 자동 업로드 | 사용자 시험 대기 |
| 원본 열기 / 새로고침 중복 방지 | 사용자 시험 대기 |
| 오프라인 촬영 후 복구 | 사용자 시험 대기 |
| 앱 종료·OS 백그라운드 전송 | 이번 시험의 보장 대상 아님 |

오류가 나면 화면의 상태 문구와 촬영 시각을 기록한다. 토큰·비밀번호·전송 세션 URI는 공유하거나 기록하지 않는다.

## 운영 메모

- 해당 주소를 Firebase Auth 승인 도메인 및 Drive 웹 OAuth 클라이언트의 JavaScript 원본·리디렉션 URI에 추가한다.
- Railway `DRIVE_WEB_ORIGINS`에 기존 주소를 유지하고 해당 HTTPS origin을 추가한다. `web_origins.py`가 이 정확한 목록을 CORS에도 사용하며 임의의 `*.web.app`은 허용하지 않는다.
- 시험 종료 후 미리보기 만료와 별개로 OAuth·Firebase Auth·Railway의 시험 주소 등록을 정리한다. 기존 주소·Drive 원본·기기 사진은 삭제하지 않는다.
